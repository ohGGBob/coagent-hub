## Phase 3 实现方案（版本升至 0.8.0）

**核心原则**：零 npm 依赖不变（用 Node 内置 fetch 调 Ollama）；append-only 模式不变（向量走 sidecar 文件）；检索 API 签名不变（`embedding` 字段当初预留就是为此）；Ollama 不可用时全量降级回 BM25，行为与现状完全一致。

### 1. `src/embed.js` — Ollama 嵌入客户端（新模块）
- 环境变量：`COAGENT_EMBED_URL`（默认 `http://127.0.0.1:11434`）、`COAGENT_EMBED_MODEL`（默认 `bge-m3`）、`COAGENT_EMBED=0` 强制关闭
- 启动探测 Ollama `/api/embed`（批量），失败指数退避重探；单次 5s 超时
- `embed(texts) → number[][]|null`：任何失败返回 null，绝不阻塞/破坏主流程；`status()` 暴露可用性/模型/维度

### 2. `src/vectors.js` — 向量 sidecar 存储（新模块）
- `data/vectors.jsonl` 追加式：`{targetId, model, dim, vec, ts}`，同 targetId 后写覆盖先写
- 内存缓存 Map targetId→Float32Array；纯 JS 余弦相似度
- `queryByVector(vec, topK)` 供检索层调用

### 3. `src/context.js` 接入
- `append()` / `revise()` 落盘后异步补嵌（fire-and-forget，不阻塞写路径）
- `query({q})` 自动 hybrid：有向量时 = 归一化余弦×0.6 + BM25×0.4；无向量条目退回 BM25 分；结果附加 `_score`/`_via`（semantic/keyword/hybrid）可选字段

### 4. `src/server.js` 接线
- 新增 `GET /embed/status`（登录即可）：`{available, provider, model, dim, coverage:{embedded,total}}`
- `/admin/export` 包含 vectors；启动时后台分批回填历史条目的缺失向量

### 5. 面板（panel.html）
- 上下文页头部：嵌入状态徽标（模型名 + 覆盖率），语义命中在结果里标注
- 任务详情模态新增「相关上下文」小区块：按任务标题/描述语义拉 top3 相关条目（上下文策展的核心价值点）

### 6. 冒烟测试（零依赖 mock）
- smoke.js 内起一个 mock Ollama 端点（node http，确定性向量），断言：探测、向量落盘、hybrid 排序生效、mock 宕机时降级 BM25 且全绿
